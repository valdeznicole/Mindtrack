`welcome-reference.png` is the reference artwork supplied by the project owner
in this design conversation. Keep it unmodified: `ProfilePortrait.jsx` displays
only the portrait using an SVG clip and changes the blue ink to emerald through
an SVG filter. The face geometry and source pixels are retained, avoiding a
different face produced by redrawing it. Page text and animated ornaments are
separate elements and are not taken from the reference image.
